## 원본과의 차이 및 검증

- React 소스 및 원본 yarn.lock 유지
- README 재작성, 출처 문서와 실제 브라우저 캡처 10장 추가
- 촬영용 API는 저장소 밖의 로컬 도구이며 애플리케이션에 포함하지 않음
- pnpm으로 의존성 설치 후 react-scripts 프로덕션 빌드 성공; 설치 시 semver 범위 안의 최신 패키지가 사용됨
- Spring Boot/MySQL/C 전체 연동 테스트는 수행하지 않음

- 팀 개발 당시 README는 `docs/README.original.md`에 보존했습니다.

## 팀 결과물 출처

원본 팀 프로젝트 코드의 저작자·출처는 원본 저장소와 개발 기록에 있습니다. 개인 저장소의 커밋은 복사본 정리와 포트폴리오 문서화를 기록하기 위한 것입니다. 별도의 라이선스는 새로 부여하지 않았습니다.
